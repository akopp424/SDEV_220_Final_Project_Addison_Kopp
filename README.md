# Coffee Shop Inventory and Sales Management System

## Description
This project is a Python application developed for my final project. It helps a coffee shop manage inventory and process customer sales through a graphical user interface (GUI).

## Features
- Add new products
- View current inventory
- Sell products
- Automatically update inventory quantities
- Generate customer receipts
- Display error messages for invalid input

## Classes
- Product
- Inventory
- SalesTransaction

## Collections Used
- Dictionary (stores inventory)
- List (stores shopping cart items)
- Tuple (stores receipt information)

## Technologies
- Python 3
- Tkinter

## How to Run
Run the program by executing:

```bash
python3 main.py
```
